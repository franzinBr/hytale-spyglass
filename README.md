![](https://hytale.com/static/images/logo.png)

Adds a craftable spyglass/telescope that lets you zoom in and scout the world from afar.

Skeleton Pirate Captains, Gunners, and Strikers can also drop one spyglass. Their default
chances are 8%, 4%, and 2%, respectively. Configure them in the plugin's `config.json`:

```json
"Drops": {
  "SkeletonPirates": {
    "CaptainChancePercent": 8.0,
    "GunnerChancePercent": 4.0,
    "StrikerChancePercent": 2.0
  }
}
```

Each chance accepts a finite value from 0 to 100; use 0 to disable a variant. Changes
take effect after a server restart or full plugin reload. Existing NPC drop lists remain untouched.

See details and dowload mod in [CurseForge](https://www.curseforge.com/hytale/mods/spyglass)
